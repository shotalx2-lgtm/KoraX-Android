# كورة X — دليل التشغيل والنشر

## محتويات المجلد
- `index.html` التطبيق كاملاً (واجهة عربية RTL + إنجليزي/فرنسي/إسباني)
- `config.js` ربط المصادر وتغيير الأصوات (الملف الوحيد الذي تحتاج تعديله)
- `sounds/` 12 مؤثراً صوتياً (MP3 مضغوط بجودة مناسبة للموبايل) — استبدلها بتسجيلات حقيقية بنفس الأسماء
- `manifest.webmanifest` + `sw.js` + `icons/` لتثبيت التطبيق على الموبايل (PWA) وتشغيله بدون نت للواجهة

## النشر (مجاني)
1. ارفع المجلد كما هو على Netlify (سحب وإفلات) أو GitHub Pages أو Cloudflare Pages.
2. افتح الرابط من الموبايل ← "إضافة إلى الشاشة الرئيسية".
> يلزم HTTPS لتثبيت التطبيق وإشعارات النظام (توفره هذه المنصات تلقائياً).

## ربط المصادر
`config.js` مضبوط افتراضياً على واجهة ESPN غير الرسمية (بدون مفتاح) للترتيب والأخبار والمباريات. هي غير موثقة وقد تتغير، ولم أتمكن من اختبارها من بيئتي، فجرّبها بعد النشر.
لأي مصدر آخر استبدل الدالة المناسبة (standings / news / matches / scorers / transfers / photo) بحيث تُرجع الشكل الموضح في التعليقات، أو `null` لعرض البيانات التجريبية.
للتحكم في الهدافين وصور اللاعبين والانتقالات الحقيقية تحتاج مصدراً لها (غير متوفر مجاناً بدون مفتاح).
ضع `demo:false` لإخفاء المباراة التجريبية عند الاعتماد على بيانات حقيقية.

## ملاحظات
- أسماء الفرق والأخبار القادمة من ESPN تكون بالإنجليزية.
- الأصوات والإشعارات داخل التطبيق تعمل بعد أول لمسة للصفحة (قيد المتصفحات).
- التطبيق ويب (PWA). للحصول على APK/متجر استخدم أداة تغليف مثل Capacitor أو PWABuilder.

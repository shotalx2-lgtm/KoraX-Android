# كورة X — مشروع Android

هذه الحزمة تحتوي على واجهة كورة X الحالية وطبقة Android WebView لتشغيلها كتطبيق Android، مع الحفاظ على ملفات الواجهة وتصميمها. لم تتم إعادة تصميم الواجهات في هذه المراجعة؛ التعديلات اقتصرت على إصلاحات البيانات والبناء ومنع عرض معلومات وهمية.

## المحتويات

- `korax-app/`: مصدر واجهة التطبيق وموصلات البيانات والصور والأصوات.
- `android/`: مشروع Android Studio/Gradle وملفات التطبيق الأصلية.
- `tests/`: اختبارات موصلات البيانات وفحص صياغة JavaScript المضمّن داخل HTML.
- `.github/workflows/android.yml`: سير عمل GitHub Actions لبناء APK.

## المصادر العامة

- ESPN public soccer feeds: مباريات ونتائج وجداول وبعض قوائم الهدافين وتفاصيل المباريات حسب التغطية. لا يتطلب مفتاح API، لكنه غير موثق كواجهة عامة مستقرة وقد تتغير مساراته أو التغطية.
- Google News RSS باللغة العربية: يجمع عناوين أخبار عالمية وعربية من ناشرين مختلفين، ويعرض اسم الناشر والتاريخ والرابط الأصلي. الصور ليست متاحة لكل خبر، لذلك يستخدم التطبيق خلفية رسومية هادئة عندما لا توجد صورة موثقة.
- OpenLigaDB: مصدر احتياطي مجاني بلا مفتاح لجدول Bundesliga فقط.

لا يوجد في الحزمة مصدر مجاني واحد بلا مفتاح تم التحقق منه لتغطية جميع الدوريات، الانتقالات الرسمية، كل الأحداث والتشكيلات والإحصائيات. لا يعرض التطبيق صفقات انتقال أو تشكيلات أو أرقامًا مختلقة عند غياب بيانات المصدر. أخبار الانتقالات معروضة كتغطية صحفية وليست صفقات مؤكدة.

## بناء APK من GitHub

عند رفع المشروع إلى المستودع على الفرع `main` يبدأ workflow تلقائيًا عند تعديل ملفات Android أو الواجهة. ويمكن تشغيله يدويًا من **Actions → Build Android APK → Run workflow**.

بعد نجاح التشغيل، نزّل Artifact باسم `KoraX-Android-debug`. يحتوي على `app-debug.apk` قابل للتثبيت والاختبار. هذه نسخة Debug موقّعة بمفتاح Android Debug، وليست نسخة متجر Play موقّعة بمفتاح إصدار خاص.

## الاختبارات

- `node tests/connectors.test.cjs`
- `node tests/check-inline-js.cjs`
- `node --check korax-app/config.js`

تم التحقق محليًا من هذه الاختبارات وصياغة ملفات JavaScript. لم يُنفذ بناء APK داخل بيئة العمل الحالية لأنها لا تحتوي على Android SDK أو Gradle، ولم يتم اختبار التطبيق على هاتف فعلي. نجاح APK يظل مشروطًا باكتمال GitHub Actions ثم تثبيت النسخة وتجربتها على جهاز Android.

## ملاحظات Android

- التطبيق Android هجين: WebView آمن يحمل نسخة محلية من واجهة الويب داخل APK.
- الأخبار العربية تُحمّل عبر جسر Android إلى Google News RSS، لتجاوز قيود CORS في WebView.
- تحديث النتائج والإشعارات يعمل أثناء تشغيل التطبيق ومراقبة البيانات. لا توجد خدمة Push دائمة بعد إغلاق التطبيق.
- لا يحتاج المشروع إلى Supabase أو API keys أو أسرار في إعدادات Android.
